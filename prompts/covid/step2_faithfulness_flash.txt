You are a careful fact-checker. You are given (A) the source report text an analyst was
allowed to cite, and (B) the analyst's reasoning about how BIG a forecast revision should
be. The analyst was asked to support the size with a SMALL number of short, targeted
evidence quotes. Every phrase inside quotation marks is presented as evidence drawn from
the report text. Check whether each quoted phrase is genuinely SUPPORTED by the report —
by MEANING, not by exact wording.

Rules:
  • Consider ONLY phrases inside quotation marks (these are the analyst's evidence quotes).
  • A quote is SUPPORTED if the report text contains a phrase or statement with the SAME
    MEANING. It does NOT need to be word-for-word. Accept minor paraphrase, reordered
    words, synonyms, truncation, or changed tense/number, AS LONG AS the report genuinely
    says the same thing.
  • A quote is UNSUPPORTED only if the report contains no statement of equivalent meaning —
    i.e. it is fabricated, materially altered, or contradicts the report.
  • Do NOT judge whether the chosen size is right — only whether the quoted evidence is
    faithful to the report's meaning.
  • If there are NO quotation marks at all, treat that as NOT faithful.

     supported in meaning and at least one is present) or "no". Example:
